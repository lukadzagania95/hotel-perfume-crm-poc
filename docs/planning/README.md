# Historical planning archive

These documents capture the original discovery phase and proposed implementation. They are preserved as design context, not as a description of the current application.

Some proposals changed: the app now has real SMTP/IMAP integration, administrator authentication, custom CSS rather than Tailwind, and a four-state opportunity lifecycle without `PENDING`.

For current behavior, start with the [project README](../../README.md), [architecture](../architecture.md), and [operations guide](../operations.md).
